# AfterPython's Project Website Template

This is a project website template for [afterpython].

## Usage

1. Clone the repository
2. Run `pnpm install` to install dependencies
3. Run `pnpm dev` to start the development server
4. Run `pnpm build` to build the project
5. Preview the build, using either:
   - `pnpm preview`, which does NOT include the pagefind build
   - `pnpm serve`, which includes the pagefind build
